# KanbanCards v1.4.0 — Calm Kanban & Planning Tools

## Added

- Added Inbox, Next, Doing, and Done workflow lanes with search, card moving, pinning, and lane reordering.
- Added archive and restore, priorities, and due-date filters for organizing cards.
- Added local due-date reminders with snoozing, dismissal, and a Settings toggle.
- Added editable checklist rows, lightweight tags, and meeting, daily-plan, and idea templates.
- Added JSON and Markdown export, JSON import preview with duplicate skipping, and SQLite backup restore.
- Added global Ctrl+Alt+N quick capture and tray-based clipboard capture.
- Added adjustable editor text size, clearer focus/accessibility states, and compact board cards.

## Updated

- Updated the note editor with a read-only, note-colored date picker and clearer calendar selection states.
- Updated tag and checklist fields with consistent insets, stronger contrast, and sticky-note-matched surfaces.
- Updated lane selectors and task-completion notifications to match the rounded card styling.
- Made the Windows installer and app self-contained so users do not need to install the .NET Desktop Runtime separately.
- Preserved existing note text and colors with additive database migrations and automatic pre-migration backups.
- Improved in-app upgrades to preserve the existing install path, startup entry, and shortcut choices.
